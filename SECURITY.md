# Güvenlik Politikası

Desteklenen sürüm: `0.1.x`.

Bir güvenlik açığı bulduysanız herkese açık issue açmadan önce GitHub'ın özel güvenlik bildirimi
özelliğini kullanın. Bildirimde etkilenen sürümü, yeniden üretim adımlarını ve olası etkisini
belirtin. Süreç yolları, kullanıcı adları veya gerçek IP adresleri içeren raporları herkese açık
alanlarda paylaşmayın.

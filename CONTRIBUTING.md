# Katkıda bulunma

Katkılar memnuniyetle karşılanır. Değişiklik yapmadan önce bir issue açarak önerinin kapsamını
konuşmanız faydalıdır.

1. Depoyu fork edin ve bir özellik dalı oluşturun.
2. `python -m pip install -e ".[dev]"` ile geliştirme bağımlılıklarını kurun.
3. Davranış değişiklikleri için test ekleyin.
4. `pytest` ve `ruff check .` komutlarını çalıştırın.
5. Küçük ve açıklayıcı bir pull request gönderin.

Güvenlik açığı olabilecek bir bulguyu herkese açık issue olarak paylaşmayın; depo sahibinin
özel güvenlik bildirim kanalını kullanın.
